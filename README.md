# Deadline Pro — V1

A mobile-first, cozy productivity app with a virtual pet. No login, backend, or database.

## Run it
Open `index.html` in a modern browser. For the most reliable behavior, use a static local server or deploy the files to a static host.

## Deploy free
1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, and `app.js` to the repository root.
3. Open the repository Settings → Pages.
4. Select deploy from the main branch and the root folder.
5. Wait for the published website link.

## Data and privacy
Tasks, pet name, happiness, growth, and streak-related data are saved in browser `localStorage` on that device/browser. There is no account or cloud sync. Clearing site data can erase progress. This is a prototype; do not enter sensitive information.

## V1 included
- Responsive dashboard
- CSS-drawn animated virtual pet
- Rename pet
- Add, edit, complete, and delete tasks
- Due dates and priorities
- Progress meter
- Pet happiness and growth
- Four evolution stages (visual stage label and progress)
- Friendly comeback messages
- Browser storage and reset control

## Notes
The app is a front-end prototype. The pet's evolution is represented by stage and progress text; more distinct character art and richer animations can be added later.
